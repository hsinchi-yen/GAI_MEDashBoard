🏭 製造業 PMI 採購經理人指數

ℹ️ PMI 指標說明

▼
PMI（Purchasing Managers' Index）是衡量製造業景氣擴張或収縮的先行指標，由採購經理人對 新訂單、生產、就業、供應商交貨、庫存 等子項進行問卷調查後編制。
  • PMI > 50：代表製造業處於擴張期，經濟活動增加
  • PMI < 50：代表製造業處於收縮期，經濟活動萎縮
  • PMI = 50：為榮枯分界線
資料來源：
  • 🇺🇸 美國：ISM（5項子指標複合）
  • 🇹🇼 台灣：CIER 中經院製造業 PMI
  • 🇨🇳 中國：NBS 國家統計局製造業 PMI
  • 🇯🇵 日本：內閣府景氣觀測調查 DI
  • 🇪🇺 歐元區：Eurostat 工業信心指標 ICI (+50)
投資意義：PMI 領先 GDP 約 1-2 季，是判斷景氣循環轉折的關鍵指標。連續 3 個月 > 50 代表復甦確認；持續下滑則預示需求放緩。

🚢 台灣出口年增率 (YoY)

ℹ️ 出口指標說明

▼
台灣出口金額 Year-over-Year 年增率，反映全球終端需求強弱。
  • YoY > 0%：出口正成長，全球需求擴張
  • YoY < 0%：出口萎縮，全球需求放緩
為何重要：台灣以半導體和電子零組件出口為主，是全球科技供應鏈的關鍵樞紐。台灣出口 YoY 通常領先全球科技股約 1-2 個月。
資料來源：財政部統計處 / FRED / OECD MEI

💰 M1B 貨幣供給年增率

ℹ️ M1B 貨幣供給說明

▼
M1B = 通貨淨額 + 支票存款 + 活期儲蓄存款。反映民間資金的「活水」程度。
  • M1B YoY 上升：資金動能增加，有利股市
  • M1B YoY > M2 YoY（黃金交叉）：資金從定存轉入活存、流入股市的訊號
  • M1B YoY < M2 YoY（死亡交叉）：資金保守化，流出股市
資料來源：中央銀行金融統計月報 / FRED (美國 M1)

📈 OECD 領先指標 (CLI)

ℹ️ CLI 領先指標說明

▼
OECD CLI（Composite Leading Indicator）是 OECD 編制的綜合領先指標，用於預測經濟轉折點。
  • CLI > 100：經濟活動高於長期趨勢
  • CLI < 100：經濟活動低於長期趨勢
  • CLI 從底部回升 → 預示經濟復甦
  • CLI 從高點下滑 → 預示景氣放緩
領先意義：CLI 通常領先 GDP 轉折 6-9 個月，是判斷套經濟週期位置的核心工具。美國 CLI 對全球股市指引性最強。
資料來源：OECD / DBnomics / FRED

📟 半導體 PPI 指數

ℹ️ 半導體 PPI 說明

▼
半導體製造業 PPI（Producer Price Index）反映半導體產業出廠價格變動，是判斷科技業成本壓力與獲利空間的關鍵指標。
  • PPI 持續上行 → 半導體供不應求，代工廠有議價權
  • PPI 下行 → 供過於求，出清壓力增加
資料來源：FRED (PCU33443344) — U.S. BLS 半導體及電子零組件製造業 PPI (1984年12月=100)

ℹ️ 原油價格說明

▼
布蘭特原油（Brent Crude）是全球原油定價基準，反映能源成本。
  • 油價過高 → 侵蝕消費能力，迫使央行維持緊縮政策
  • 油價暴跌 → 可能反映全球需求急凍（如衰退信號）

🚨 VIX 波動率指數

ℹ️ VIX 恐慌指數說明

▼
VIX（CBOE Volatility Index）又稱「恐慌指數」，衡量市場對 S&P 500 未來 30 天波動程度的預期。
  • VIX < 20：市場處於低波動/正常狀態
  • VIX 20-30：市場警戒，波動加大
  • VIX > 30：市場恐慌，可能出現劇烈震盪
  • VIX > 40：極度恐慌，歷史級別事件
投資策略：VIX 飆升時市場通常超賣，逢高買入波動率保險（如 VIX Call）可對沖風險。反向投資者關注 VIX 從高位回落作為進場信號。
資料來源：FRED (VIXCLS)

📉 美國公債殖利率

ℹ️ 殖利率曲線說明

▼
殖利率曲線描繪不同天期美國公債的殖利率水準。
  • 正常（正斜率）：長期利率 > 短期利率，經濟預期健康
  • 倒掛（負斜率）：短期利率 > 長期利率，為衰退的強烈預兆
  • 10Y-2Y 利差：最受關注的倒掛指標，歷史上曾預測每次美國衰退
目前焦點：10Y-2Y 利差從倒掛解除轉正後，通常是景氣末段或衰退即將開始的信號（歷史平均領先衰退 12-18 個月）。
資料來源：FRED (DGS各天期)

😊 消費者信心指數

ℹ️ 消費者信心說明

▼
密西根大學消費者信心指數（UMich Consumer Sentiment）由密西根大學每月調查美國消費者對當前及未來經濟狀況的看法。
  • 指數上升 → 消費者對經濟有信心，消費意願增強
  • 指數下降 → 消費者轉趨悲觀，可能減少支出
  • 基期：1966年 Q1 = 100
投資意義：消費佔美國 GDP 近 70%，消費者信心下降通常預示零售銷售與 GDP 增速放緩，是景氣轉弱的另一個先行信號。
資料來源：FRED (UMCSENT)
